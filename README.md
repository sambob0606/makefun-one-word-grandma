One word a grandma would text about AI. A tiny deterministic Python program (standard library only) that scores a shortlist of grandma-words against the judge's five published criteria and writes the winner to `/output/entry.txt`. The winner is **Gizmo** — the word grandmas actually use for a newfangled device they don't understand: warm, a little baffled, and it names a machine.

## Run it

```sh
python3 main.py
```
